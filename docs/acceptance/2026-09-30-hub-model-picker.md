# Hub 模型选择验收

## 交付

- 按钮旁的浮动菜单直接按供应商分组列出可用模型。模型、看图能力和思考档位读 DSH，
  首页不再补写固定型号，也不单独合并 OAuth 状态覆盖后端判断。
- 能力收成看图、联网、搜图、生图四项，支持悬停和键盘聚焦说明。
- 登录和 Key 留在右上角设置；工具导航隐藏，模型页注明以后开发。
- `/slides/models`、health、意图判断、创建、恢复和切换模型使用同一目录。
  注销不会污染下一次读取或另一个 home。模型 ID 中的斜杠保持完整。
- 修复启动请求结束时关闭用户已打开面板的竞态；空列表及读取失败禁止发送，
  保留偏好并支持重新打开重试。
- OAuth 包装插件补声明 `connection` 依赖。真实状态接口从 400 恢复为正常的
  认证后 200 / 未认证 401，保留 DSH 原有会话边界。

接口契约见 `docs/architecture/hub-model-catalog.md`；界面约定见 `DESIGN.md` 的
「Hub 模型选择与能力提示」。

## 轻量菜单补充验收

用户确认取消宽大的内嵌面板。本轮改成约 300px 的浮层，去掉标题、下拉框和两栏网格。
模型直接点选，当前项显示勾选；选择后收起。思考档位是分段单选，切换档位不收起。
能力仍保留四项及说明。首页整体留白没有调整。

- 菜单不改变输入卡片高度。1440/390/320 宽度与 420px 短窗口均在视口内。
- 模型 listbox 支持方向键、Home/End 和原生按钮的 Enter/Space；思考 radiogroup
  支持方向键。Esc 回到触发按钮，点外部、Tab 离开和打开其他菜单均收起。
- 长列表内部滚动。异步目录及能力刷新保持菜单内键盘焦点，不误收起菜单。
- 空目录/网络错误保留已存偏好并禁止发送；重开可以恢复。含斜杠的型号与实际
  选择的 `low` 档位完整进入持久 launch 请求。
- 最终源码串行 native-web 180/180、client 3/3；oracle、生产边界、秘密扫描、
  `git diff --check` 通过。最初的 Hub 驱动未等待异步能力加载，修正等待后通过，
  不把那次 80/81 记为成功。

最终 Hub 三轮均为 81/81，最后一轮使用两个 CPU 负载进程。证据在
`output/qa-verify-openslides/2026-09-30T03-51-13-015Z/`、
`2026-09-30T03-51-32-030Z/`、`2026-09-30T03-51-49-349Z/`。

浮层真实服务截图和机器记录在 `output/qa-hub-model-popup/accepted/`：
warm/ink 各 1440/390/320，有档位菜单，以及两主题 1440/390 空态。空态明确使用
目录测试替身，不声称真实服务没有可用模型。真实接口读取和设置状态未使用替身，
订阅状态仍为 200，浏览器 `pageerror` 为空。已复核菜单密度、文字、思考档位、
输入卡片尺寸与窄屏边界，未见本轮 P0/P1 问题。
