## 框选的产品决定与实测

保留框选。用途是对一组对象写一条共同意见，例如「这一组说明的字号加大」。每个对象需要不同要求时，分别标注，最后从对话统一发送。

进入批注模式后，单击对象或从空白处直接拖框；持续提示操作方式，拖动时显示对象数量。松手后浮卡出现在光标旁，显示当前页与对象数，可用 Shift 点击增减。添加后回到画布继续标记，意见自动进入左侧对话。Esc 取消草稿并退出批注。没有独立的范围切换按钮、右侧提交或解决步骤。

原生浏览器实测：拖框选中第二条建议的标题和说明，共 2 个对象；Shift 加入第三条标题后为 3 个，再次点击减回 2 个。编辑选框与旋转/拖拽手柄数为 0。Esc 后浮卡与提示隐藏，没有新增批注或改动文稿。1440、877、375 宽的边缘定位与键盘流程由固定 Playwright 回归覆盖。

## 修复与回归边界

- Host 的 reviewScope.items 按 pageId 对应 editorEdit.pages，允许多条意见共享一页；各意见仍保留自己的对象集合。
- Host 工具与 presentation-run 落盘层共用 `reviewWriteTargets` / `reviewWriteTargetForPage`，按页合并执行权限，不使用批注第一条的范围代替整批。混合整页与对象批注时，各页权限独立。
- 锁保存每页原始页面内容；完成接口在写锁内检查全部意见对应的实际变化、页内越界、非目标页变化和文稿设置。少完成一条或越界时拒绝成功确认，客户端恢复修改前快照并保留意见。
- 手动编辑过的每个页面在批量提交前获得有效的 ledger 修订号。
