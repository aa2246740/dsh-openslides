## 根因与改动

原分类提示把“全局风格、主题、配色”直接归为 deck，并允许历史范围影响新请求。原文稿的“用SVG设计点背景吧”因此被授权为两页：V19 的 note 为 deck:1_cover,2_tips。

现在逐条判断新请求：未指定范围默认当前页，明确页码保留完整集合，明确所有页面才选择全文；只有明确确认尚待执行方案的回复才承接其范围。背景、SVG、风格、配色本身不是全文范围。

非 current 分类须引用本次消息的范围原文；承接方案还要引用真实历史。解析器拒绝缺失或虚构引用的决策。该机制只验证引用来源，语义仍由所选模型判断，不宣称数学上保证所有自然语言都分类正确。前端继续仅映射结构化范围，不增加页码正则、模式菜单或确认弹窗。模型原生能力中有 low 推理档才启用该档，推理分类保留 2048 token 上限。
