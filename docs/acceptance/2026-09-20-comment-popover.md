# 光标旁的批注浮卡

按用户要求，取消右侧常驻批注面板。进入批注模式后，点击对象会在点击位置旁显示输入浮卡；点编号显示该条批注；“全部批注”才展开列表与跨页选择。浮卡不挤压画布，空间不足时换边，随画布位置与窗口变化重新定位。

添加仍只保存意见并附到左侧对话；AI 只从左侧发送。浮卡里的对象目标只显示一次，移除了重复 hover tooltip。点击外部收起，Esc 退出批注并恢复工具栏焦点；草稿保留。

## 证据

- 固定 Playwright 1.61.1 / Chromium 1228：38 项批注与范围锁相关测试通过；最终浮卡 UI 的 5 项相关测试再次通过。覆盖旧选区释放、对象/多选、编号、保存、草稿、外部点击、Esc 和文稿逐字节不变。
- 1440、877、375 像素宽的浮卡截图均检查：卡片在屏幕内、不盖住点击点、不预留右侧栏；375 宽时浮卡会覆盖部分画布，收起后可继续操作。
- `editor-comment-batch.mjs` 15 步通过：全部批注入口 → 跨页 3 条/2 页 → 左侧单次发送 → 一个模型回合、一个快照；失败保留附件并从同一入口重试。回合使用 stub，实际批注服务及落盘参与验收。
- `editor-ai-workspace-comment-agent.mjs` 通过：临时项目批注持久化、刷新恢复、无 AI 会话时诚实报错，页面与标题不变。修正其旧的全局模型读取，改为始终指定临时项目，避免并发用户页面造成误判。
- 原生浏览器在用户城市步行项目中验收了新建浮卡、全部批注入口、外部点击收起和已有编号打开。“用红色的字”原样保留，没有调用模型执行它。
