# DSH SlideStudio 0.2.1

## 安装

桌面端打开 **插件 → 添加插件**，输入 `dsh-slidestudio`，安装后点击 **立即启用**。

Web profile：

```sh
dsh plugin --profile web add dsh-slidestudio
```

发布包遵循官方 npm 包与 `dsh.bundle.patch` 约定，包含预编译服务端、客户端和生产依赖。Personal 为可选依赖；使用 Personal 入口需 0.2.8 或更新的 0.2.x。

生成前仍需配置 DSH 模型及 Playwright 1.61.1 / Chromium Headless Shell 1228 运行时。包不包含浏览器，也不会在安装时下载浏览器。完整说明见 [INSTALL-DSH.md](../../INSTALL-DSH.md)。

## 修复

- 生成过程中关闭 AI 工作区后可以重新打开；首张页面尚未生成时也可操作。
- 设置按钮通过 Harness 已渲染的设置控件打开设置，修复原生桌面端忽略模拟快捷键的问题。关闭设置后返回原入口；失败时显示提示。
- 项目数据与插件安装目录分离。已连接的源码工作区保留原位置；后续卸载重装继续读取同一份项目。
- 等待编辑器服务就绪后才转发首次请求，避免刚启用插件时页面加载失败。
- 独立入口使用官方桌面标题栏留白变量，避免 macOS 窗口按钮遮挡稿件标题。
- 统一 npm 包名、插件 ID、双语元数据与 README 安装说明，清理发布包中的开发及历史文件。
