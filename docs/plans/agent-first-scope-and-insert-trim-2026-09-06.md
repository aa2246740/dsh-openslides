# Agent主创：精简插入与明确修改范围

## 决策

编辑器用于纠正Agent产出。移除手动插入图标、SmartArt、公式的入口；保留文稿中已有对象的渲染、基础编辑和Agent底层生成能力。普通形状、线条、文字、图片、表格、图表继续保留。

左侧直接对话的目标必须来自用户表达，发送前可见，后端严格限定同一页集合，不能只在提示词里约束。

| 表达 | 目标 |
| --- | --- |
| 背景换成浅蓝色（没有范围） | 当前页，残留选区不改变这个默认值 |
| 本页所有文字改成深色 | 当前页，所有文字不等于所有页面 |
| 修改所选对象/选中文字 | 当前选区；空选区不发送并说明 |
| 第2页/第二页 | 指定页，允许不切换当前画布 |
| 第2、4页/第2和第4页 | 精确两页子集 |
| 第2至4页/第2-4页 | 精确连续页子集 |
| 全部都改/整个PPT背景换一下 | 整稿，保留范围确认及修改前版本 |
| 不要改整份，只改第2页 | 第2页 |
| 越界、矛盾或不能可靠确定的复杂排除表达 | 不发送，给出可修正说明，禁止默认回当前页或整稿 |

## 实施边界

- 页面序号按当前文稿顺序映射稳定pageId，排序去重。
- 单页/多页子集/整稿范围贯穿解析、目标提示、锁定、权威版本同步、Host授权、写入guard、结果核验、恢复。
- 多页子集不能借用整稿scope扩大权限；未授权页面、元素顺序及无关元数据仍受保护。
- 不新增复杂手动编辑面板。批注继续绑定明确元素，不能被左侧默认范围变更影响。
- 生产由Luna实施，独立QA检查脚本和后端限制，root负责实际13080和真实模型验收。

## 验收

1. 菜单没有三个已砍入口，shape/line可用，已有icon/SmartArt仍正常展示。
2. 单元与隔离UI矩阵覆盖目标表达、选择残留、否定、非法页码、精确payload、未授权页拒绝及失败恢复。
3. 原生真实模型在独立稿验证默认当前页、非当前指定页、多页子集、整稿背景；比对磁盘确认范围、保存与完成状态。
4. 备份部署到13080，保留用户文稿；记录通过项及未覆盖边界，不沿用旧“默认选区”断言冒充新行为。

## 追加决策：手动工具继续收敛

按用户反馈，移除插入图表、页面背景按钮及画布右键背景入口，删除对应背景/主题手动面板。图表创建、数据配置、背景调整交给左侧 Agent；已有图表的显示和属性纠错保留。手动插入只保留文字、形状/线条、图片、表格。
