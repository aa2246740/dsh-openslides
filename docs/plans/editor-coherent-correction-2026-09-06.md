# 编辑器交互收敛实施计划

状态：实施中。目标是 Agent 主创、人类纠错的在线编辑器；不以按钮能触发命令作为可用性结论。

## 决策快照

- 保留现有浅色、低干扰画布。固定插入栏、页面导航、右侧属性、左侧 Agent 是稳定区域。
- 属性面板属于当前选区；首要内容是对象类型和准确目标。文字/图片等自身属性与对象位置、外观分组。
- 采用有标题的紧凑分区、直接字段和明确开关。避免长列嵌套按钮、无意义卡片套卡片和重复菜单。
- 字体继承现有 UI tokens；分区标题与字段标签层级明确；普通字段不依赖 tooltip 才能理解。
- 同一属性栏每个动作只有一个常规入口；右键和快捷键作为有意保留的快捷路径，不算栏内重复。

## 实施包 A：属性栏信息架构（Luna 实现，root 验收）

1. 移除属性栏“更多”容器，将其现有能力分配到明确分区，不删除支持的能力。
2. 文字分区：字号/字体与常用字形、文字颜色、文本对齐、列表、链接；常用字段直接可见，额外排版选项可明确展开。
3. 文本框分区：真实 checkbox/switch“框内自动换行”，明确已开/已关；说明只按框宽换行，不宣称自动增高/缩字号。
4. 位置与排列：位置 X/Y、宽/高、旋转、翻转；“对象对齐”明确单选相对页面、多选相对选区；分布仅合理多选时可用；图层四动作只保留一套；编组/解组/锁定/隐藏各一处且体现状态。
5. 外观：不透明度与数值、阴影等，不再藏在“更多”。
6. 固定常用动作区域：复制副本、删除（紧凑横排），避免和滚动属性混淆，不遮挡尾部控件。
7. 图片：替换、裁切为清楚入口；移除重复裁切按钮，遮罩和填充模式归图片属性；任何重建提示改为页内表单，标明真实能力，失败保留输入。
8. 形状、线条、图标、表格、图表、SmartArt保持各自编辑能力，放入对应命名分区；按当前类型显示，中文命名一致。
9. 多选只显示真正可作用于整组选区的操作；混合锁定禁用状态与原因清楚。空选区、隐藏对象、历史只读、Agent忙碌有明确状态和恢复入口。

## 实施包 B：统一交互和状态

- 展开区最多两级，保持当前对象操作后展开状态与焦点；切对象不会留下失效弹层。
- Enter提交、Escape取消、点击外部关闭的规则依照字段/弹窗语义一致；有未保存输入时不静默丢失。
- 明确开关状态；按钮图标、名称与实际命令一致；disabled不是唯一解释，必要时有可见状态说明。
- 排查所有编辑器 window.prompt/confirm 依赖，当前已知图片重建 prompt 必须替换；保留已验收的链接 dialog。
- 所有新可交互控件复用既有oracle control IDs；新增ID须相应记录。不要伪造未实现的功能。
- 保持clipboard四交叉路径、富文本选区、AI精确element IDs、stop/restore、背景字段和响应式折叠已修复行为。

## 实施包 C：空间和视觉验收

- 宽度1100/1375/1440/1920；另外检查窄屏现有overlay与Escape退出，不能破坏桌面策略。
- AI开/关 × 属性开/关 × 单选/多选：画布保持主位，用户主动展开被尊重。
- 用真实内容长标签、长字体名、空值、无效数值查看截断、对齐、滚动、焦点环。
- 截图先看整体，再看二级区；不能靠同色长列表把一切堆进属性栏。

## 验收矩阵和完成门槛

- 无选择、文字、形状、图片、线条、图标、表格、图表、SmartArt、单选/多选、locked/hidden、只读/Agent忙碌。
- 每个受影响动作核对实际模型/文件变化，撤销或恢复、重载，不只click成功。
- 连续旅程：局部改字/格式→缩窄文本框/换行→对齐对象→重排层级→复制/删/撤销→精确Agent指令；图片替换/裁切/取消；表格/图表数值纠错。
- 原生 IAB 人工验收；headless仅使用全局pinned runtime。系统IME未验证的边界继续如实保留。
- 根因和修复记录在证据账本，新增缺陷回归。不能通过改弱断言或删测试掩盖产品回归。
- 部署必须逐文件备份、哈希一致，13080实际实例验证；测试用独立稿，保留用户文稿。不要触碰DSH.app。
- 完成条件：实施包已落地、已知P0/P1均解决、必要回归通过、root原生验收和部署通过；计划不是最终交付。

## 审计追加：已确认的流程缺陷

- P0：live生成轮询失败会把phase设为disconnected，并错误释放人类写保护。保持同session写保护直到权威终态，导航继续可用；断连文案不得承诺后台已停止。
- P1：批注“解决”先乐观隐藏、保存不await。改为每项busy，保存成功后完成；失败保留可见并提示重试。
- P1：批注加载中/失败被当空列表。明确loading、error、ready、缓存回退提示与重试入口。
- P1：无生成session/events的Agent面板提前return，空状态分支不执行。显示准确的目标说明/示例，不留空白对话区。

这些是本轮总流程审计的必要修复，生产仍由单一Luna实施者写入，独立恢复测试由流程审计worker负责。

### 最终收尾清单

- P1：局部文字格式提交后一次点击缩略图必须切页；不能因重绘替换按钮而丢失导航，也不能产生无变化的撤销记录。
- P1：大表格插入改为单次原子命令，失败不留下半张表，一次撤销移除整个新增表格。后端由流程 worker 独立负责，前端由主实施者接入。
- P1：插入、翻页、撤销等命令失败统一给出可见原因，同时保留调用者的失败处理与回滚语义。
- P1：原生图表数字修改后立即关闭会取消待保存计时器并丢失输入；关闭、切选、切页必须提交到原图表，失败或非法输入保留明确恢复路径。
- P1：真实人类编辑后页内容与AI ledger不一致，新批注可能拿到null pageRevision。锁定时先校验批注是否仍指向当前内容，仅对有效新批注在项目写锁内登记当前页的新revision；陈旧批注仍拒绝，Host范围验证不放宽。
- P1：图表自动保存后blur不得再次提交相同值；一次实际修改只产生一次可撤销事务。
- P2：插入菜单 Escape、焦点与 ARIA；页面右键菜单视口边界、焦点返回、拖动取消及当前页语义；版本菜单滚动与触发器语义。
- P2：普通文字形式的公式入口明确叫“公式文本”；高亮颜色反映真实状态并提供清除。

以上为本轮冻结的收尾范围，落实后进入统一回归和实际实例验收。
