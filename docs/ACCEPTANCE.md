# 部署验收手册（Cola）

目标：你在自己的机器上 clone、启动、走完 **创建 → 生成 → 编辑 → 导出**，判断这条主路径能不能交。

这不是 Phase G，也不是官方 1:1。能交的标准是：**按本文操作，不需要问我们「该跑哪条命令」。**

## 0. 环境

- Node.js **22.19+**
- 现代浏览器（Chrome / Edge 即可）
- 至少一个已登录的供应商（API Key 或 OAuth）
- 可选：WPS 或 PowerPoint，用来打开导出的 `.pptx`

## 1. 启动

```bash
git clone <本仓库>
cd open-slidestudio
npm install
npm start
```

终端应出现类似：

```
Open SlideStudio  http://127.0.0.1:55200/
创建 Hub 是默认首页。编辑器: http://127.0.0.1:55200/index.html
```

浏览器打开 **http://127.0.0.1:13080/** ，根路径会转到 **`/app/hub.html`**。

### 过关

- 首页是「创建」：大输入框「一句话，把想法变成漂亮的演示文稿」（带 `?project=` 的旧链接仍进编辑器）
- 能看到 **本地工作台 / 幻灯片 / 自适应 / 当前供应商**
- **不要**打开 `localhost:5173`，那是旧栈

若 55200 被占用：`SLIDES_EDITOR_PORT=55201 npm start`；Hub/内核端口用 `SLIDES_DSH_PORT`（默认 13080，勿占 DSH.app 的 3080）。其余环境变量见根目录 `.env.example`。

## 2. 生成一稿（真实 DSH Agent Run）

1. 在输入框写一句中文，例如：`华北区域三季度增长复盘，咨询风，含图表`
2. 产出类型保持 **幻灯片**（文档是「即将支持」，点不了）
3. 版式保持 **自适应**（4:3 是「即将支持」）
4. 点击供应商按钮，用 API Key 或 OAuth 登录；可选填写模型名
5. 点右下角向上箭头发送

应进入生成页，看到若干工具行在跑，最后出现结果卡（封面底色 + 标题 +「编辑」）。

点 **编辑** 进入编辑器。

### 过关

- 时间线能看到真实的原文读取（`list_references` / `read_reference`）、计划提交（`commit_design` / `write_todo`）、逐页 `write_page / render_page / review_page`、结构审查 `review_pages` 和 `compose_deck`
- 结果卡标题来自简报，不是英文占位
- 编辑器能看到多页缩略图和一页画布
- `GET /slides/state/:sessionId` 返回 `kernel: "dsh"`、`hostDirected: false`，`inspection` 里逐字节原文回执、计划覆盖、写页数、磁盘页数、逐页渲染与审查、布局和结构审查一致；`/api/generate` 和 `/api/generate-status` 应返回 410（Pi 时代接口已退役）
- 任一页改写后，旧截图和旧审查立即失效；文字溢出、越界、字体未就绪或正文侵入页脚区时不能显示成功
- `write_todo` 和逐页脚本要求的图表、表格、漏斗、仪表盘、金字塔、KPI 卡必须以可编辑 PPTD 对象真实存在；用一段文字描述图表不能过关
- 逐页脚本锁定的数字必须留在对应页，不能近似、四舍五入、挪页或丢负号；图表和表格里的数值同样计入核对
- 任何失败都不得切到 Playbook、套完整页面模板或把残片显示为成功

## 3. 编辑器点一遍

在当前稿上至少做这些（都应该立刻有反应）：

| 动作 | 期望 |
|---|---|
| 双击一段字，改几个字，点空白 | 文字留下 |
| 底栏 **T** 插入文本，直接打字 | 进入编辑态 |
| 插入形状，拖一下，改填充色 | 形状跟着走，颜色是路径填充不是只涂外框 |
| 插入表格，双击单元格改字，+行 / +列 | 表变了 |
| 插入图表，点 **编辑数据**，改一个数字 | 图跟着变 |
| 插入图片（任选一张本机图），点 **裁切**，拖边 | 进入裁切，完成/Esc 退出；不要一进来就缩一圈 |
| 底栏 **批注**，在形状上钉一条，再点 **编辑** | 批注层关掉 |
| 标题栏 **V1 ▾ → 保存当前为新版本** | 列表变长；点旧版本出现「只读」，**回到最新** 退出 |
| **放映**，再 Esc | 进播放，底栏隐藏；退出后底栏回来 |
| 信封图标 **消息** | 弹出说明（本地无云端收件箱），不是没反应 |

撤销 / 重做应能用。

## 4. 导出 PPTX

1. 点 **导出**
2. 选 **PowerPoint**
3. 等进度变成结果（文件名 · 页数 · 大小）
4. 用 WPS 或 PowerPoint 打开下载的文件

### 过关

- 打开后能改标题文字、表格单元格
- 图表能进「编辑数据」一类入口（不是整页一张图）
- 导出对话框只提供 PPT / PDF / 图片三种格式（Google 幻灯片已从产品移除）

PNG 是当前页预览，不是主交付。

## 5. 附件（可选）

回到 Hub（编辑器左上角 ← 或关）。

1. 点 **+**
2. 应看到中文：「把文件拖到这里上传」
3. 可 **选择文件**，或点 **品牌样例** 加入本地样例
4. 再生成一次：结果说明里应提到参考了资料

解析不了的 Office 二进制会标「已记录·不可解析」，这是诚实降级，不是坏了。

## 6. 供应商登录与失败关闭

1. 点当前模型，打开选择面板：只有供应商、模型、thinking 与真实登录状态；API Key 输入、账号登录、退出都不在这里
2. 面板里的「登录 / 供应商设置」跳到设置：模型页填 API Key，订阅登录页完成账号授权。登录只在这两处发生
3. 切换到一个未登录供应商后发送，应停在登录提示，不能生成
4. API Key 登录后页面不得回显 Key；OAuth 只显示授权状态
5. 对 `/api/generate` 发送任何生成请求，应返回 410（该接口已退役；Hub 生成走 `POST /slides/sessions`），不能创建成功结果
6. 模型超时、额度 403/429、登录失效、过载、工具中断或本地进程退出时，未完成项目只能暂停，不能显示成功
7. 补额度、重新登录或切到另一个已登录供应商后，点「马上重试」；路径必须保持不变，并从 RunLedger（`_agent/run-ledger.v1.json`）的未完成闸门继续
8. 恢复会为新模型上下文重新逐块读取原文并重新提交计划；已经落盘的 todo、页面和通过的页面审查不能被宿主模板替换
9. 只要严格运行的 `_agent/runtime.json` 和 RunLedger 完整，服务应能重建恢复指针（`presentation-run.v1.json` / `attempt.v1.json`）；它不得伪造聊天记录或页面
10. 流式生成必须在调用供应商前先返回项目路径；创建页把该路径持久保存。即使连接或进程没有机会返回暂停消息，重新打开产品后仍能找到同一运行
11. 同供应商自动换模型时，每个新模型上下文都必须重新读取最新 RunLedger。跨供应商恢复只使用用户当前选择且已登录的供应商，不得自行产生额外费用

联网搜索、看图等能力由所选供应商/模型和已配置工具决定；产品不人为关闭模型自带能力。能力卡必须如实显示当前可用项。

### 6.1 结构门禁 v5 的客观审美层（2026-08-21，部分已随 ADR-0008 修订失效）

> **注：** 本节记录的「九轴 `review_deck` / 整稿审美审查」闸门是 Pi 时代产物，已在 ADR-0008 修订中移除——DSH 工具面没有 `render_deck` / `review_deck`。`review_pages` 结构审查与下面的可测量硬指标仍然有效；把它当历史记录读，不要再要求 taste/deck 总览回执。

自 `structural-review-gate-v5` 起，taste-gated 严格运行的 `review_pages` 先过一层可测量的硬指标
（`TASTE_GATE_LIMITS`，见 `docs/architecture/taste-execution-contract.md`）：

- 标题字级：内容页 ≥ 20pt，封面/封底 ≥ 28pt；正文辅助文案 ≥ 11pt（底部页脚/页码 chrome 豁免）
- 密度预算：每内容页 ≤ 900 字、≤ 48 个可见元素、元素面积和 ≤ 1.35 倍版面
- 图表构图：每页 ≤ 2 张图表，且单张 ≥ 200×140
- 编辑留白：文字不得距左右边 12pt 以内

该层是必要条件而非充分条件：数字过关仍可能被九轴 review_deck 打回；模型判断永不因数字达标而升级。
首个真实项目已按 v5 重审：修复前 43 处违规 / 19 页，重审后 0 处；导出
`澄光生活-2026年7月经营月报-v5验收.pptx`（20 页原生 slide part、21 个可编辑 chart part、22 个内嵌工作簿、零整页位图，
coverage=1.0、degradations=0）。

## 7. 明确还没做完（验收时不要当 bug 开回去）

- 不是官方生成队列，没有账号升级套餐
- 文档长文、4:3 画布：按钮禁用，文案是「即将支持」
- 分享只有本地链接，没有云端权限和多人同时改
- 主观设计质量还未设分数门槛；当前硬门槛是“确由 Agent 新设计”，不是模板替换或宿主补画
- 官方 iframe 双通道截图、像素描摹 SVG 皮未齐
- **不要**对外说 Phase G / 1:1 已完成

## 8. 开发者门禁（你不一定要跑）

```bash
npm run test:native
npm run gate:native
npm run qa:all
npm run native:check -- --project <现有项目目录> --brief-file <原始简报>
```

`qa:all` 会起 55200 上的原生壳，跑全部 `scripts/verify-*.mjs`。
`native:check` 只读磁盘，不启动内核、不调用供应商、不改页面；任何承诺展项、锁定数字或当前回执缺失都会返回非零退出码和 JSON 清单。

`npm run dev`、`dev:api`、`dev:web`、`localhost:5173` 是归档产品（`LEGACY.md`）。根 README 已不再把它当主路径。
