# Editor coherent-correction acceptance matrix

Status: implementation acceptance in progress (2026-09-06). This matrix covers the inspector rewrite in `docs/plans/editor-coherent-correction-2026-09-06.md`. A rendered control or successful click is not sufficient evidence: affected actions require returned-model mutation, undo/redo where supported, and reload/disk persistence.

## Evidence contract

| Level | Required evidence | Meaning |
|---|---|---|
| S — surface | Accurate selected-target label; correct named sections for the current type; explicit enabled/disabled/pressed/checked state; no clipped or horizontally overflowing control at 1100/1375/1440/1920 px. | The control is discoverable and understandable. |
| M — mutation | `/api/command` request has the expected command and selected element IDs; the returned `/api/model` changes only the intended fields/elements. | The control acts on the intended model scope. |
| P — persistence | Undo restores the prior model; redo restores the mutation when applicable; navigation/reload reads the same state from the disposable PPTD fixture. | The change is durable and reversible. |
| N — native | Codex native IAB interaction with the real form/dialog and keyboard behavior. | Browser-native prompts, native pickers, system IME and signed-in provider behavior are not inferred from headless Chromium. |

Automated runs must use `launchPinnedChromium` from the repository adapter backed by `~/.codex/playwright-runtime/runtime.mjs`, a random localhost port, and a disposable fixture under the OS temporary directory. They must not contact ports 13080 or 55200 or mutate a user project.

## Required end-to-end journeys

1. Text correction: edit a local range, change style, narrow the text box, toggle frame wrapping, object-align, change layer order, duplicate, delete, undo/redo, reload, then send an exact selected-element Agent instruction. Verify each step against model/disk and Agent element IDs.
2. Image correction: replace an image, enter crop, drag once, exit with Escape, verify that the already-applied crop remains and the UI explains undo, undo once to restore the prior crop, redo/reload, then open inline rebuild and retain its instruction on failure. Crop Escape is an exit path, not a transactional cancel.
3. Data correction: edit the last table cell and final chart data cell, close immediately, reopen, reload/export, and verify the stored values rather than only the rendered labels.
4. Clipboard/link regression: UI link and Cmd-K save/modify/cancel/reject/remove plus all four keyboard/context clipboard crossings remain green. External plain text must not revive stale internal object clipboard state.
5. Agent scope regression: selected-element requests carry exact element IDs; current-page and whole-deck scopes remain distinguishable; stop/restore and review locks do not silently widen scope.

## Responsive matrix

| Width | AI closed / inspector open | AI open / inspector open | AI open / inspector user-collapsed | Multi-select and long fields |
|---:|---|---|---|---|
| 1100 | Canvas controls and fixed common actions visible; no horizontal page scroll. | Current auto-collapse policy may apply, but the user can reopen the inspector and both panels remain reachable. | User choice is retained through resize and selection mutation. | No clipped labels/inputs; panel scroll reaches final action. |
| 1375 | Inspector remains a stable right region. | Auto-collapse behavior is explicit and reversible. | Manual override is respected. | Same bounds checks as 1100. |
| 1440 | Inspector and canvas retain primary hierarchy. | Boundary behavior does not flap at exactly 1440. | Manual override is respected. | Same bounds checks as 1100. |
| 1920 | Canvas grows without stretching inspector rows into long sparse controls. | AI and inspector coexist without masking canvas actions. | Collapse/expand remains keyboard reachable. | Same bounds checks as 1100. |

For every viewport, assert document `scrollWidth <= clientWidth`, selected canvas visibility, inspector/client rectangles within the viewport, last common action reachable after scroll, and no active section/form detached from its selected object.
