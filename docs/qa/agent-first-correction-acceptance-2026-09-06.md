# Agent 主创、人类纠错：补充验收

## 产品目标

Agent 完成主要创作；人类应能准确选择问题位置、做小幅改动，或将明确范围交给 Agent，并能确认结果、停止和恢复。验收以连续纠错流程为单位，不以按钮数量或完整 PowerPoint 对齐为完成条件。

## 本轮发现和修复

1. 多选对象直接发 Agent 指令时范围退化成整页；单选指令仍引用 write_page。现单/多选统一为 elements 精确集合，仅发布及要求 edit_elements。
2. 运行时隐藏了唯一停止入口。现运行面板显示“停止修改”，走同一停止、等待结束、恢复版本流程。
3. 当前修改过程混入整段生成历史。现运行时突出本次 turn，完整历史保留为次级内容。
4. IME 组合阶段 Escape 会取消整段编辑。已添加 composition/isComposing/keyCode229 保护并通过合成事件回归。
5. 混合锁定选区的移动、层级、删除仍可点击。现按整个选区禁用，保留解锁及合理可用操作。
6. 外部粘贴忽略系统文本，并可能贴入陈旧的内部对象。现基于标准剪贴板事件区分内部对象标记和外部纯文本；外部文本一次原子插入，输入框和文本编辑保留原生粘贴。
7. 右键菜单焦点、Escape、边缘范围及背景色入口不一致。现背景设置回到可见持久字段，菜单支持键盘及视口约束。
8. 品牌图标错误使用900字重。现匹配 Brands字体400字重，三风格可见图标逐项检查。
9. 后台 raster 使用普通打开接口污染其他标签的全局项目与版本状态。已使用隔离视图请求和独立临时 session；部署后真实 render_page 通过，前景项目、页码、选区与版本均未被污染，后续编辑可保存并重载。

10. 右键与快捷键剪贴板两套路径不一致。现统一标准 text/plain + text/html 对象凭据，四种交叉操作已通过；权限被拒不执行隐藏替代操作，显示可操作的快捷键提示。
11. AI、缩略图和对象属性同时展开时，1280宽画布缩至33%。已按窗口临时收起属性，尊重用户本次主动展开；901–1180档AI320px、缩略图136px。实际1100窗口画布384→540px，40%→56%，无横向溢出。
12. 小窗口隐藏插入按钮文字后缺少可访问名称。已补5个固定插入按钮的 aria-label，实际实例原生可访问名称复验通过。
