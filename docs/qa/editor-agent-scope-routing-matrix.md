# 编辑器 Agent 范围路由验收矩阵

状态：前端范围、请求合同、手动入口、既有内容与 Host 写页双重门禁均已通过独立冻结门禁（2026-09-06）。本轮只验证编辑器 Agent 范围解析、授权与越界保护，以及手动插入入口收敛；不评价模型生成质量。

自动化必须通过仓库适配器调用 `~/.codex/playwright-runtime/runtime.mjs`，使用随机本地端口和临时复制的八页 fixture。不得访问 13080、55200 或用户项目。

## 产品语义

1. 左侧 Agent 默认目标始终是当前页，即使画布仍有选区。
2. 只有提示词明确写出“所选对象 / 选中的对象”等对象范围时，目标才变为 `elements`，并冻结当时完整且有序的元素 ID 集合。
3. 提示词中的明确页码优先于残留选区。支持 `第2页`、`第二页`、`第2、4页`、`第2和第4页`、`第2-4页`，解析结果必须是精确页集。
4. 明确要求整份 PPT 的背景或全稿修改时，目标为整份文稿；不能因当前页或选区状态缩窄范围。
5. 越界页码、空页集或互相矛盾的范围不创建版本、不申请锁、不发送 turn，并在输入附近给出可恢复说明。
6. 页、页集和整稿的授权是后端硬边界。Agent 对非授权页、当前页替换、全稿元数据或页面顺序的写入必须在持久化前被拒绝。
7. 现有批注到 Agent 的精确元素范围保持不变；工作区默认当前页的新语义不能把批注范围降级为整页。
8. 手动“图标 / SmartArt / 公式文本”插入入口消失，但已存在的这三类内容仍能加载、显示、选择、编辑、撤销和重载，Agent 仍可在授权页内创建或修改对应原生内容。
9. 明确的页面背景改色意图可携带受范围约束的背景覆写授权，使 `background.color` 接受合法的浅蓝或非主题色板 hex；普通标题、文字、形状或主题修改不得获得该授权。

| 层级 | 必须核对 | 通过条件 |

| 持久化边界 | 页面文件 SHA、返回模型、版本、undo/redo、reload | 只有授权页发生变化；一次撤销恢复该请求；版本恢复点存在；重载读取相同结果；后端越界尝试不产生部分写入 |

## 后端 guard 注入

每个 guard 用例都先记录全部八页文件 SHA 和 deck 元数据，再执行一次被授权写入与一次越界写入：

| ID | 授权 | 注入尝试 | 通过条件 |
|---|---|---|---|
| SG-01 | 非当前第 2 页 | 写第 3 页 | 在持久化前拒绝；八页与 deck SHA 均不变 |
| SG-02 | 页集第 2、4 页 | 写第 3 页或把 `targetPages` 扩成第 2–4 页 | 拒绝整个请求；第 2、4 页也不能留下部分结果 |
| SG-03 | 页集第 2–4 页 | 改 deck 主题、标题或页面顺序 | 拒绝并恢复；三页内容和 deck 元数据均不变 |
| SG-04 | 整稿背景 | 漏掉一页或加入不存在页 | 锁或验证失败；不接受“部分完成”为成功 |
| SG-05 | 精确元素批注 | 改同页非目标元素、页面元数据或元素顺序 | `scopeViolation=true`，恢复版本；批注不标记为已应用 |
| SG-06 | 第 2、4 页背景改色，合法非色板 hex | 只改两页的 `background.color` | 允许写入两页；第 3 页与 deck 元数据不变；非法颜色、结构变化和陈旧 CAS 继续拒绝 |
| SG-07 | 普通第 2 页标题修改 | 同时尝试非色板背景色 | 背景写入在持久化前拒绝；标题范围不能借用背景覆写 |

## 批注回归

创建一条绑定两个元素的批注，核对持久化 scope、锁、turn 中的 `reviewScope.elementIds` 均为同一精确集合。成功只允许这两个对象变化；越界对象注入必须被 guard 拒绝并恢复。此路径不经过工作区默认范围推断。

## 旧断言迁移说明

`editor-agent-human-audit.mjs` 原先通过画布选区直接期待 `#work-target` 显示“已选 2 个对象”，并期待下一次 turn 自动使用 `elements`。该断言对应旧产品语义。本轮改为两步：先证明残留选区下默认仍是当前页，再输入明确包含“选中的两个对象”的提示，证明目标切换到精确元素范围。断言仍核对相同元素 ID、`edit_elements` 限制与后端 guard，不通过放宽 ID 或只检查文案来适配。
