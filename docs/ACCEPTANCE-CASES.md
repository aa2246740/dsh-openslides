## 0. 预测用户会做的事（先写再测）

任何人打开编辑器，通常会：

1. 把鼠标滑过顶栏 / 底栏，看有没有 hover
2. 点每个插入按钮
3. 拖元素、拖表格、拖页
4. 双击改字、改单元格
5. 右键、撤销、放映、导出
6. 试禁用项会不会假装能用

下面按面拆开。每条都带「可能的误操作」。

## 8. 明确还不能声称「对照过官方每一个按钮」

- 动画时间轴已从编辑器藏起（官方 iframe 无时钟）。裁切把手、图标弹层的**像素皮**仍在对照中（`oracle:inventory` + 官方全屏）
- 官方生成队列、账号（`wont-port`）；Google Slides 导出已从产品移除（不是灰置）
- Docs / 4:3（即将支持）

登录官方账号**不是**复刻编辑器的前提。对照机已经把可编辑稿送进 iframe。
