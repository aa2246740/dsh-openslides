# Classroom

Use only when the brief is a 讲一讲 / K-12 lesson.

## Learning first

Name the learner, the exit capability, and one learning action per page. Then write pages.

## Pages

`cover` → `route` → `concept` → `method` → `demo` → `transfer`.

- cover: blush circle + green title band. Title is the lesson.
- route: coral short rule + vertical spine + four stations. One name and one note each.
- concept: coral rule + two columns (definition left, parts right).
- method: three condition panels (water / air / warmth).
- demo: top band + two-column evidence + result bar.
- transfer: result line + next-action panel.

`write_page` may use recipe atoms (`cover-botanical`, `route-path`, `method-panels`, `two-column-45-55`, `demo-band`, `result-bar`, `next-action`) or the same PPTD shapes. The host will not rewrite your elements.

Tokens: paper `#FDFAF5`, title `#44712E`, body `#56687A`, coral `#F5987E`, leaf `#D7EBCE`, blush `#F9DED8`.

## Seed lesson

Only if the brief is about 种子 / 发芽: title `种子怎么发芽`; stations `先喝饱水` / `种皮裂开` / `小根钻出来` / `芽顶出土`; concept `种皮` / `子叶` / `胚`; method water / air / warmth.

Any other lesson keeps these six types and writes copy from that brief.
