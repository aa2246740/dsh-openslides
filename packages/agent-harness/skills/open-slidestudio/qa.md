# Review

`render_page` is a native `#slide` screenshot, not the official iframe.

Check every page:

1. The title states the reader task.
2. One exhibit carries the page; support does not compete with it.
3. Type fits its box (no overflow).
4. Contrast holds. Bounds stay inside 960×540.
5. Numbers and names are sourced or marked 占位.
6. `src` files exist, or there is no image element.

Vision off: say so, then run this list on the YAML. Fix with `write_page`, render again, then `compose_deck`.
