# Scenario

Pick one primary scenario from the brief, then set page count.

| Scenario | Brief cues | Reader task | Pages |
|---|---|---|---|
| Classroom | 讲一讲, 年级, 课件, 小学生 | Understand, remember, apply | 6: cover → route → concept → method → demo → transfer |
| Travel | 旅游, 攻略, 行程, 东京 | Decide where to go and in what order | Cover + one exhibit per day or area + close. A 7-day brief is not six classroom pages |
| Report | 周报, 月报, 复盘 | See status, blockers, next | Follow the material. One exhibit per cluster. No padding |
| Decision | 尽调, 战略, 增长 | Form a judgment | Cover judgment → evidence → so-what → next |
| Promo | 发布会, 品牌, 营销 | Leave one memory | Cover → one memory page → one exhibit → close |
| Academic | 开题, 答辩, 论文 | Evaluate method and gaps | Cover → question → method → materials → close |

User-stated page count wins. An outline attachment wins. Topic-only: use the table. Quote attachments; invent nothing.
