# DSH SlideStudio

AI presentations for DeepSeek Harness — describe your deck in one line, let AI write, lay out and render it, then edit on the canvas and export an editable PPTX. 中文界面自动跟随 DSH 语言设置。

- One-line brief → full deck, rendered live in the app
- Edit text, images and styles directly on the canvas
- Annotate any element, or hand it to the AI assistant
- Native editable PPTX export (PowerPoint / WPS ready)
- Uses the DSH model catalog — configure models in DSH Settings
- Works standalone (top-level nav entry) or inside the Personal sidebar

See the repository README for installation.
